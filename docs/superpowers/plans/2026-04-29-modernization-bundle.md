# Modernization Bundle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete daedalOS → maeveOS rebrand, finish Yarn 4 migration, replace BrowserFS with ZenFS — in three sequential, independently revertable phases on a single branch.

**Architecture:** Phase 1 (rebrand) is mechanical string changes. Phase 2 (Yarn) is build-infra cleanup. Phase 3 (ZenFS) replaces the runtime FS layer in `contexts/fileSystem/` plus fans out type-only updates to ~20 consumer files. The static read-layer index is regenerated by a rewritten `scripts/fs2json.js`. Runtime archive/Emscripten/FileSystemAccess mounts move from `extrafs.min.js` to ZenFS-equivalent backends.

**Tech Stack:** Next.js 15, React 19, TypeScript, Yarn 4 (`node-modules` linker), Jest, Playwright, ZenFS (`@zenfs/core`, `@zenfs/dom`, `@zenfs/archives`).

**Spec:** `docs/superpowers/specs/2026-04-29-modernization-bundle-design.md`

- [ ] **Step 2: Rewrite `scripts/fs2json.js` to emit the ZenFS Fetch index format**

The current script emits `{ fsroot: [[name,size,mtime,target]...], size, version: 4 }`. The ZenFS Fetch backend expects (based on `@zenfs/dom` source — confirm against your notes) a flat object map from absolute path to `{ size, mtime, mode, ... }` plus directory entries.

Implementation outline (adapt to the actual schema in your notes):

```js
const { mkdir, readdir, readlink, stat, writeFile } = require("fs");
const { basename, dirname, join, resolve: resolvePath } = require("path");

const args = process.argv.slice(2);
const argPath = resolvePath(args[args.length - 1]);
let excludedPaths = [];
let outputPath = "";

args.forEach((arg, index) => {
  if (arg === "--exclude") excludedPaths = args[index + 1].split(",");
  if (arg === "--out") outputPath = resolvePath(args[index + 1]);
});

const FILE_MODE = 0o100644;
const DIR_MODE = 0o040755;
const SYMLINK_MODE = 0o120777;

const buildIndex = async (root) => {
  const entries = {};

  const walk = async (dir, virtualPath) => {
    const files = await new Promise((res, rej) =>
      readdir(dir, (err, list) => (err ? rej(err) : res(list)))
    );
    const filtered =
      dir === root ? files.filter((f) => !excludedPaths.includes(f)) : files;

    const childNames = [];

    for (const file of filtered) {
      const full = join(dir, file);
      const v = virtualPath === "/" ? `/${file}` : `${virtualPath}/${file}`;
      const st = await new Promise((res, rej) =>
        stat(full, (err, s) => (err ? rej(err) : res(s)))
      );

      if (st.isSymbolicLink()) {
        const target = await new Promise((res, rej) =>
          readlink(full, (err, l) => (err ? rej(err) : res(l)))
        );
        entries[v] = { mode: SYMLINK_MODE, size: st.size, mtimeMs: +st.mtime, target };
      } else if (st.isDirectory()) {
        entries[v] = { mode: DIR_MODE, size: st.size, mtimeMs: +st.mtime };
        await walk(full, v);
      } else {
        entries[v] = { mode: FILE_MODE, size: st.size, mtimeMs: +st.mtime };
      }
      childNames.push(file);
    }

    if (!entries[virtualPath]) {
      entries[virtualPath] = { mode: DIR_MODE, size: 0, mtimeMs: 0 };
    }
  };

  await walk(root, "/");
  return entries;
};

(async () => {
  console.info("Creating ZenFS Fetch index ...");
  const index = await buildIndex(argPath);
  await new Promise((res) =>
    mkdir(dirname(outputPath), { recursive: true }, () => res())
  );
  await new Promise((res) =>
    writeFile(outputPath, JSON.stringify(index), () => res())
  );
  console.info(`Wrote ${Object.keys(index).length} entries to ${outputPath}`);
})();
```

**Adjust the `entries[v] = { ... }` shape to match the schema you documented in Task 3.1's notes.** The skeleton above is a reasonable guess; the actual ZenFS `Fetch` backend may use different property names (e.g., `mtime` vs `mtimeMs`, `entries` array on directories, etc.). Use the documented schema, not this guess.

### Task 3.5: Rewrite `contexts/fileSystem/useAsyncFs.ts` to wrap ZenFS

**Files:**
- Modify: `contexts/fileSystem/useAsyncFs.ts`

The current file is a 300-line callback-to-promise wrapper around BrowserFS. ZenFS exposes `fs/promises` natively, so this simplifies dramatically. Keep the exported function names so consumers don't need to change.

- [ ] **Step 1: Replace the file with a ZenFS-backed implementation**

```ts
import { useEffect, useMemo, useState } from "react";
import { configure, fs as zenSyncFs } from "@zenfs/core";
import { promises as zenFsPromises } from "@zenfs/core";
import type { Stats } from "@zenfs/core";
import {
  ICON_CACHE,
  ICON_CACHE_EXTENSION,
  SESSION_FILE,
} from "utils/constants";
import { join } from "path";
import FileSystemConfig from "contexts/fileSystem/FileSystemConfig";
import { supportsIndexedDB } from "contexts/fileSystem/core";

export type AsyncFS = {
  exists: (path: string) => Promise<boolean>;
  lstat: (path: string) => Promise<Stats>;
  mkdir: (path: string, overwrite?: boolean) => Promise<boolean>;
  readFile: (path: string) => Promise<Buffer>;
  readdir: (path: string) => Promise<string[]>;
  rename: (oldPath: string, newPath: string) => Promise<boolean>;
  rmdir: (path: string) => Promise<boolean>;
  stat: (path: string) => Promise<Stats>;
  unlink: (path: string) => Promise<boolean>;
  writeFile: (
    path: string,
    data: Buffer | string,
    overwrite?: boolean
  ) => Promise<boolean>;
};

// RootFileSystem in BrowserFS exposed mntMap/mountList. ZenFS exposes mounts
// via `mounts` (Map<string, FileSystem>). We expose a thin wrapper here so
// existing call sites that read `rootFs.mntMap` / `rootFs.umount` keep working.
export type Mount = { _data?: Buffer; data?: Buffer; getName: () => string };
export type RootFileSystem = {
  mntMap: Record<string, Mount>;
  mountList: string[];
  mount: (path: string, fs: unknown) => void;
  umount: (path: string) => void;
};

type AsyncFSModule = AsyncFS & {
  fs?: typeof zenSyncFs;
  rootFs?: RootFileSystem;
};

// Legacy types that consumers still import from this module — keep the
// names stable but back them with empty/best-effort definitions.
export type EmscriptenFS = { DB_NAME: () => string; DB_STORE_NAME: string };
export type ExtendedEmscriptenFileSystem = { _FS?: EmscriptenFS; getName: () => string };

let configuredOnce = false;

const buildRootFs = (): RootFileSystem => {
  // ZenFS exposes mounted backends through a `mounts` map on the
  // VirtualFileSystem object. Adapt to whatever the documented API is.
  // Reference: docs/superpowers/notes/zenfs-api-mapping.md
  return {
    mntMap: {},     // populated lazily by mount()/umount() callers below
    mountList: [],
    mount: () => {
      throw new Error("ZenFS mount() not yet wired — see useFileSystemContextState");
    },
    umount: () => {
      throw new Error("ZenFS umount() not yet wired — see useFileSystemContextState");
    },
  };
};

const useAsyncFs = (): AsyncFSModule => {
  const [ready, setReady] = useState(false);
  const [rootFs, setRootFs] = useState<RootFileSystem>();

  const asyncFs: AsyncFS = useMemo(
    () => ({
      exists: async (path) => {
        try {
          await zenFsPromises.stat(path);
          return true;
        } catch {
          return false;
        }
      },
      lstat: (path) => zenFsPromises.lstat(path),
      mkdir: async (path, overwrite = false) => {
        try {
          await zenFsPromises.mkdir(path);
          return true;
        } catch (e: any) {
          if (overwrite && e?.code === "EEXIST") return true;
          throw e;
        }
      },
      readFile: async (path) => Buffer.from(await zenFsPromises.readFile(path)),
      readdir: (path) => zenFsPromises.readdir(path),
      rename: async (oldPath, newPath) => {
        try {
          await zenFsPromises.rename(oldPath, newPath);
          return true;
        } catch (e: any) {
          if (e?.code === "ENOTSUP") {
            const stats = await zenFsPromises.lstat(oldPath);
            if (stats.isDirectory()) {
              throw new Error("Renaming directories is not supported.");
            }
            const data = await zenFsPromises.readFile(oldPath);
            await zenFsPromises.writeFile(newPath, data);
            return false;
          }
          throw e;
        }
      },
      rmdir: async (path) => {
        await zenFsPromises.rmdir(path);
        return true;
      },
      stat: (path) => zenFsPromises.stat(path),
      unlink: async (path) => {
        await zenFsPromises.unlink(path);
        return true;
      },
      writeFile: async (path, data, overwrite = false) => {
        try {
          await zenFsPromises.writeFile(path, data as any, {
            flag: overwrite ? "w" : "wx",
          });
        } catch (e: any) {
          if (e?.code === "ENOENT" && e?.path === "/") {
            const { resetStorage } = await import("contexts/fileSystem/functions");
            await resetStorage(rootFs).finally(() => window.location.reload());
            return false;
          }
          if (e?.code !== "EEXIST" || !overwrite) throw e;
        }

        // Best-effort icon cache invalidation
        try {
          if (path !== SESSION_FILE) {
            const cachedIconPath = join(ICON_CACHE, `${path}${ICON_CACHE_EXTENSION}`);
            try {
              await zenFsPromises.unlink(cachedIconPath);
            } catch {
              /* ignore */
            }
          }
        } catch {
          /* ignore */
        }

        return true;
      },
    }),
    [rootFs]
  );

  useEffect(() => {
    if (configuredOnce) return;
    configuredOnce = true;

    supportsIndexedDB().then(async (canUseIDB) => {
      await configure(FileSystemConfig(!canUseIDB) as any);
      setRootFs(buildRootFs());
      setReady(true);
    });
  }, []);

  return useMemo(
    () => ({ ...asyncFs, fs: ready ? zenSyncFs : undefined, rootFs }),
    [asyncFs, ready, rootFs]
  );
};

export default useAsyncFs;
```

**Two important caveats:**

1. The `RootFileSystem` returned by `buildRootFs()` is currently a stub. `mntMap`, `mount`, and `umount` need to be wired to ZenFS's actual mount registry — done in Task 3.7 once we know the exact API from the research notes.
2. `FSModule` (from `browserfs/dist/node/core/FS`) was the BrowserFS sync FS interface. Consumers of `fs` (mostly low-level workers) get ZenFS's `zenSyncFs` instead. Type signatures may differ; downstream type errors are addressed in Task 3.8.

```ts
          } catch {

          }
          try {

          }

    } catch {

    }
  });

export const hasIndexedDB = async (name: string): Promise<boolean> =>
  new Promise((resolve) => {
    try {
      const db = window.indexedDB.open(name);
      db.addEventListener("upgradeneeded", () => {
        db.transaction?.abort();
        resolve(false);
      });
      db.addEventListener("success", () => {
        db.result.close();
        resolve(true);
      });
      db.addEventListener("error", () => resolve(false));
      db.addEventListener("blocked", () => resolve(false));
    } catch {
      resolve(false);
    }
  });

      FS_HANDLES
    ) as Promise<FileSystemHandles>)) ||

};

export const isMountedFolder = (mount?: Mount): boolean =>

export const getMountUrl = (
  url: string,
  mntMap: Record<string, Mount>
): string | undefined => {
  if (url === "/") return "";
  if (mntMap[url] || MOUNTABLE_EXTENSIONS.has(extname(url))) return url;
  return Object.keys(mntMap)
    .filter((mountedUrl) => mountedUrl !== "/")
    .find(
      (mountedUrl) => url === mountedUrl || url.startsWith(`${mountedUrl}/`)
    );
};
```

```ts
import { mount as zenMount, umount as zenUmount, mounts as zenMounts } from "@zenfs/core";

const buildRootFs = (): RootFileSystem => {
  const adapter = (): Record<string, Mount> => {
    const map: Record<string, Mount> = {};
    for (const [path, fs] of zenMounts.entries()) {
      map[path] = {
        getName: () => (fs as any).constructor?.name ?? "Unknown",
      };
    }
    return map;
  };

  return {
    get mntMap() {
      return adapter();
    },
    get mountList() {
      return Array.from(zenMounts.keys());
    },
    mount: (path, fs) => zenMount(path, fs as any),
    umount: (path) => zenUmount(path),
  } as unknown as RootFileSystem;
};
```

```ts
import { umount } from "@zenfs/core";
// ... keep other imports

export const resetStorage = (rootFs?: RootFileSystem): Promise<void> =>
  new Promise((resolve, reject) => {
    setTimeout(reject, 750);

    window.localStorage.clear();
    window.sessionStorage.clear();

    const clearFs = async (): Promise<void> => {
      // ZenFS doesn't expose Overlay's writable.empty() in a stable form.
      // Strategy: unmount the root, delete the IDB store directly, remount.
      try {
        umount("/");
      } catch {
        /* not mounted */
      }
      const { deleteDB } = await import("idb");
      try {
        await deleteDB("maeveos");
      } catch {
        /* ignore */
      }
      // Caller is expected to reload the page after this resolves;
      // a fresh page load will re-run `configure()` from useAsyncFs and
      // recreate the IDB store empty.
      resolve();
    };

    if (window.indexedDB) {
      import("idb").then(({ deleteDB }) => {
        if (window.indexedDB.databases) {
          window.indexedDB
            .databases()
            .then((databases) =>
              databases
                .filter(({ name }) => name && name !== "maeveos")
                .forEach(({ name }) => deleteDB(name as string))
            )
            .then(clearFs)
            .catch(clearFs);
        } else {
          KNOWN_IDB_DBS.forEach((name) => deleteDB(name));
          clearFs();
        }
      });
    } else {
      clearFs();
    }
  });
```
